### 📚 Assignment #1: Formula-Based Programs
This assignment implements basic physics and mathematical formulas in C++.

**Programs Included**:
   1. `01_Distance_Third_Equation_of_Motion.cpp` - Calculates distance using S = (vf² - vi²) / 2a
   2. `02_Distance_Second_Equation_of_Motion.cpp` - Calculates distance using S = vi*t + 1/2*a*t²
   3. `03_Area_of_Circle.cpp` - Calculates area using A = πr²

**Concepts Covered**: Variables, Data Types, Input/Output, Arithmetic Operators.

### 📚 Assignment #2: Problem Solving With Arithmetic Operators
This assignment solves real-life daily problems using only Arithmetic Operators without using if-else or loops.

**Programs Included**:
   1. `01_Shopping_Bill.cpp` - Total bill from price and quantity of items
   2. `02_Monthly_Electricity_Bill.cpp` - Calculates total charges from Units * Price per Unit
   3. `03_Student_Marks_Calculator.cpp` - Total, Average and Percentage of 5 subjects
   4. `04_Salary_Calculator.cpp` - Gross Salary = Basic + HRA + Medical Allowance
   5. `05_Petrol_Expense_Calculator.cpp` - Fuel consumed and total fuel cost
   6. `06_Restaurant_Bill_Sharing.cpp` - Per person bill = Total Bill / No. of Friends
   7. `07_Age_Calculator.cpp` - Age in Years, Months, Weeks and Days
   8. `08_Water_Tank_Capacity.cpp` - Volume = L*W*H and Capacity in Litres
   9. `09_Simple_Profit_Calculator.cpp` - Total Cost, Revenue and Profit/Loss
   10. `10_Time_Conversion.cpp` - Converts seconds into Hours, Minutes and Seconds

**Concepts Covered**: `cin` / `cout`, Arithmetic Operators `+ - * / %`

### 📚 Assignment #3: Decision Making With Simple If - Real Life Scenarios
This assignment focuses on decision making using only **Simple If Statement** without using if-else, else-if or loops.

**Programs Included**:
   1. `01_Student_Scholarship.cpp` - Eligible if Marks >= 85 AND Attendance >= 90%
   2. `02_Online_Shopping_Free_Delivery.cpp` - Qualified if Amount >= Rs. 3000
   3. `03_Mobile_Battery_Alert.cpp` - Alert if Battery <= 15%
   4. `04_Library_Book_Fine.cpp` - Fine if Overdue Days > 0
   5. `05_Hospital_Emergency_Alert.cpp` - Alert if Temperature >= 39°C
   6. `06_Parking_Fee_Discount.cpp` - Discount if Student ID == 1 AND Hours >= 2
   7. `07_Office_Attendance_Warning.cpp` - Warning if Attendance < 75%
   8. `08_Smart_Home_Temperature_Control.cpp` - Turn On Cooling if Temp > 30°C
   9. `09_Bank_Minimum_Balance_Alert.cpp` - Alert if Balance < Rs. 5000
   10. `10_Road_Speed_Monitoring.cpp` - Violated if Speed > Speed Limit
   11. `11_Online_Exam_Time_Alert.cpp` - Warning if Remaining Time <= 5 minutes

**Concepts Covered**: Relational Operators `> < >= <= ==`, Logical Operator `&&`, Simple `if` Statement
