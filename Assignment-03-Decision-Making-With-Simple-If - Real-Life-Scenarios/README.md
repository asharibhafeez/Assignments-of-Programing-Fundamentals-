# Assignment #03: Decision Making With Simple If - Real Life Scenarios 

This folder contains Assignment #03 for Programming Fundamentals.
All programs are solved using only **Simple If Statement** without using if-else, else-if, loops, or built-in functions.

**Total Programs:** 11

**Status:** Completed & Tested - 05-11-2026

**Language:** C++

---

### Programs List:

 *  **01_Student_Scholarship.cpp**
    - Checks if student is eligible for scholarship based on marks and attendance
    - Logic: `Eligible if Marks >= 85 AND Attendance >= 90%`

 *  **02_Online_Shopping_Free_Delivery.cpp**
    - Checks if shopping amount qualifies for free delivery
    - Logic: `Qualified if Amount >= Rs. 3000`

 *  **03_Mobile_Battery_Alert.cpp**
    - Displays low battery warning when battery is low
    - Logic: `Alert if Battery <= 15%`

 *  **04_Library_Book_Fine.cpp**
    - Displays fine message if book is returned late
    - Logic: `Fine if Overdue Days > 0`

 *  **05_Hospital_Emergency_Alert.cpp**
    - Checks for high fever and shows medical alert
    - Logic: `Alert if Temperature >= 39°C`

 *  **06_Parking_Fee_Discount.cpp**
    - Checks if student parking discount is applicable
    - Logic: `Discount if Student ID == 1 AND Parking Hours >= 2`

 *  **07_Office_Attendance_Warning.cpp**
    - Displays warning if employee attendance is below required percentage
    - Logic: `Warning if Attendance < 75%`

 *  **08_Smart_Home_Temperature_Control.cpp**
    - Turns on cooling system if room temperature is high
    - Logic: `Turn On if Temperature > 30°C`

 *  **09_Bank_Minimum_Balance_Alert.cpp**
    - Displays alert if account balance is below minimum limit
    - Logic: `Alert if Balance < Rs. 5000`

 *  **10_Road_Speed_Monitoring.cpp**
    - Checks if vehicle violates the speed limit
    - Logic: `Violated if Vehicle Speed > Speed Limit`

 *  **11_Online_Exam_Time_Alert.cpp**
    - Displays warning when exam time is about to end
    - Logic: `Warning if Remaining Time <= 5 minutes`

### Concepts Covered:
- Variables & Data Types
- Input/Output (cin / cout)
- Relational Operators: `>  <  >=  <=  ==`
- Logical Operator: `&& (AND)`
- Decision Making: Simple `if` Statement Only

**Note:** All programs take input from user (cin) and only simple if is used as per assignment rules. No if-else or loops are used.
