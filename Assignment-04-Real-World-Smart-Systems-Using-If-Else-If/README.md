# Assignment-04-Real-World-Smart-Systems-Using-If-Else-If-Ladder

### Programming Fundamentals - C++ - Decision Making with if-else-if Ladder

This repository contains Assignment 04 of Programming Fundamentals series. This assignment includes 11 Real-World Smart Systems developed using only **simple if, if-else, and if-else-if ladder** statements.

### Concepts Covered
- Decision Making
- if, if-else, if-else-if ladder
- Real-world problem solving in C++
